# Obsidian 事项与完整备份

在设置的「Obsidian 事项」中选择文件夹，例如 `E:\Data\Documents\Vault\Daymark`。点击「立即同步」导入当前内容，再点击「保存」记住目录；以后启动时自动同步。同步失败保留上次的事项和当前输入。只读取所选目录直属的 `.md` 文件，不跟随文件符号链接，不递归扫描整个仓库。

每个文件是一条大事项，标题为文件名。文件属性示例：

```yaml
---
parent: "[[另一事项]]"
tags:
  - 主业
  - 副业
---
```

不写 `parent`、留空或填写「最顶层事项」表示顶层。双链必须指向本次目录中的文件；支持双链别名和带仓库目录的双链。Obsidian 通常会在文件改名时更新双链，未更新的父链会阻止同步。`tags` 使用现有标签名称或完整路径，例如 `主业/研发`；缺失标签自动创建，重名且无法定位时要求使用完整路径。子事项继承全部父事项标签。

```markdown
- [ ] 方案调研 | 对比三种方案
    - [/] 等待确认 | | 已发出问题
    - [-] 取消方案
- [x] 完成验证 | 验证核心流程 | 测试通过
```

三个字段依次为名称、描述、结果，后两个可以省略或留空。缩进支持空格和制表符。正文中的竖线写为 `\|`；双链别名和行内代码里的竖线保留。代码块中的示例复选框不导入。

| Markdown | 事项页状态 | 记录名称候选 |
| --- | --- | --- |
| `[ ]` | 待办 | 显示 |
| `[/]` | 暂停 | 隐藏 |
| `[-]` | 已取消 | 隐藏 |
| `[x]` / `[X]` | 已完成 | 隐藏 |

Tasks 官方格式中的标签、优先级、日期、重复规则、完成后行为、依赖和任务标识会从三个显示字段中过滤；也支持相应的 Dataview 方括号或圆括号字段。原始行和完整文件内容仍保存在事项来源中。未知的复选框状态、缺失名称、重复 ID、无效 YAML 或父链循环会报错，保留现有数据。

## 稳定身份与单向同步

第一次同步会为文件加入 `<!-- daymark-file:唯一ID -->`，为每条事项在行末加入 `<!-- daymark:唯一ID -->`。HTML 注释在 Markdown 渲染中隐藏；源码中仍能看到。改名、变更缩进或跨文件移动时，请连同行末注释一起保留，文件改名时也保留文件内注释。复制一条事项建立另一条独立事项时，移除副本的 ID 注释；重复 ID 会阻止同步，避免历史记录归错事项。

同步只向 Markdown 添加身份注释，不改写内容、状态或元数据。写回前会检查文件是否变化，并将需要添加 ID 的原始文件保存到数据目录的 `obsidian-originals/*.json`。如果只完成了部分文件的 ID 写入，重试时会复用已写入的 ID。

Markdown 是导入字段的来源，导入事项在 Daymark 事项页只读；请在 Obsidian 中修改后同步。本地新建事项继续支持原有编辑。源中删除的文件或事项不会从 Daymark 删除，而是标记「源中已移除，历史保留」，从记录候选隐藏。重新出现时按 ID 恢复。记录始终引用事项 ID，原有标题、备注、时间和记录标签不随同步重写。

名称列仅搜索待办事项，按完整匹配、前缀、中间文字依次排序，不推荐标签。不匹配时可直接输入自由名称，并在标签列手动选择标签；仍允许未分类记录。选择事项自动补全继承标签，保留手动选择的标签。标签列支持多个标签，重复选择某一标签会移除它，「未归类」清空记录标签并保留已关联事项。

## 完整事项树备份

应用保持 `items.json` 版本 1；新增的可选 `source` 包含目录、文件名、源类型、原始文本、顺序和是否已移除。旧事项无需迁移。原来的事件 CSV 前六列和 UTF-8 BOM 保留，沿用当前分支已有的第七列 `item_id`；多个标签继续写在带 CSV 引号保护的 `tag_id` 字段中。

应用启动、成功修改数据、跨日和正常关闭时，在数据目录内维护：

| 文件 | 内容与保留方式 |
| --- | --- |
| `tree-backups/latest.json` | 当前完整事项树、标签和全部已保存记录，覆盖更新 |
| `tree-backups/yesterday.json` | 上一个有快照日期的最终版本，跨日覆盖一次 |
| `tree-backups/monthly/YYYY-MM-01.json` | 每月 1 日首次成功快照，长期保留且不覆盖 |

所有状态及事项属性、层级、记录关联、原始 Markdown 均包含在快照中，未保存草稿不进入备份。快照记录真实日期；若某日没有运行软件，无法补造当天状态，「昨日」文件实际保存最近一次有快照的日期，也不会补造错过的月初。月初首次快照代表当天开始使用时的状态。

快照与工作数据都使用同目录原子替换。备份失败时，当前数据保存会回滚并报告失败；损坏快照保留原文件，不静默覆盖。`archive.json` 仍独立负责完成日期的归档，与完整事项树备份各自保留。备份是重构核心数据的独立 JSON，包含完整源文件的节点可用于重建 Markdown。复制或人工恢复整个数据目录前，应先关闭 Daymark。

格式依据：[Tasks Emoji Format](https://github.com/obsidian-tasks-group/obsidian-tasks/blob/main/docs/Reference/Task%20Formats/Tasks%20Emoji%20Format.md)、[Dataview Format](https://github.com/obsidian-tasks-group/obsidian-tasks/blob/main/docs/Reference/Task%20Formats/Dataview%20Format.md)。
