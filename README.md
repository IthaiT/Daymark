# Daymark

一个本地运行的 Flutter / Dart 桌面时间记录与记账工具。

Windows 界面采用共享的 Material 3 主题、面板和标签组件，内置 Noto Sans SC 中英文字体与 Material 色板。时间记录和记账的背景、字号、间距、圆角与控件一致。标签写入 JSON，事件写入 CSV，兼容原版数据；不需要 Web 服务。

## 开发环境

安装 Flutter stable（已验证 3.47.7 / Dart 3.13.5）及 Visual Studio 2022 的「使用 C++ 的桌面开发」工作负载。用 `flutter doctor -v` 检查 Windows 工具链。Flutter 插件链接需要 Windows 开发者模式或具备创建符号链接权限的终端。

```powershell
flutter pub get
flutter run -d windows
# 构建后双击 start.cmd，或运行 ./start.ps1
./tools/build_windows.ps1
```

发行时复制整个 `build/windows/x64/runner/Release/` 目录，包含 DLL 和 Flutter 的 `data/` 资源；单独复制 EXE 不足以运行。独立发行版默认将用户记录保存在 EXE 旁的 `journal/`，也可传入 `--data-dir`。仓库启动脚本始终默认使用项目原有的 `data/`。

## 功能

- 任意层级的标签：新增、重命名、移动到其他父标签。
- 手动记录事件的开始和结束时间，提供日历和小时、分钟选择器。
- 修改事件内容、标签和时间，删除事件。
- 按日期浏览横向时间轴和事件明细。
- 标签树右键管理、拖拽移动，事件使用树状下拉选择标签。
- 本地存储，不上传数据。
- 左侧图标栏切换「时间记录 / 记账」，两套分类独立，时间记录页保持原有录入流程。
- 常用支出连续键盘录入、账户余额自动联动、转账、校准、月流水和逐层分类统计。

## 使用方法

1. 在左侧标签上右键，选择「新增子标签」「修改标签」或「删除标签」。在树的空白处右键可新增一级标签；双击只展开或收起分支。
2. 将标签拖到另一个标签上，整个分支会移动到该标签下。拖到树的空白处，或右键选择「移至一级标签」，可将分支移到顶层。不允许移动到自己或自己的子标签中。
3. 点击列表上方的「新增事件」、按 Ctrl+N，或双击表格空白处，直接生成一行草稿并聚焦名称，无需填写新增弹窗。每次新增都会生成独立草稿，可以同时创建多条未命名事件，先拖拽安排时间再分别起名。表格已满时会自动滚动到新草稿。新增事件默认接在所选日期最后一个完整事件或草稿的结束时间之后，持续一小时。当天没有完整事件时，今天从当前时间开始，其他日期从 09:00 开始；临近午夜可以跨日。若已有事件覆盖到次日，新草稿从当天 23:00 开始，以便仍可在当前日期编辑。默认未分类。填写名称后按 Enter 或离开输入框保存，Tab 保存并进入下一列；在草稿名称框按 Esc 只放弃当前这一条草稿。未命名草稿只保留在当前界面，切换日期或关闭软件会丢弃；也可以先拖拽草稿的时间再命名。
4. 在明细中选中事件后，单击标签单元格打开树状下拉框，展开分支，单击目标标签即可选定并关闭下拉框。标签弹窗与左侧标签栏使用相同的色点、层级缩进和选中样式，右侧箭头展开或收起分支。事件可使用任意层级标签，也可保持「未分类」。名称为空时选择标签，会自动使用标签名并保存；已有名称保持原样。「未定义」空档选定标签后也默认使用标签名，已改名的空档保留名称。单击日期输入框选择日期，单击时间输入框选择小时和分钟，然后点击「确定」。按 Esc 可关闭选择器并继续输入；也可以直接输入 YYYY-MM-DD 和 HH:MM。支持跨午夜，不需要输入秒。
5. 在时间轴上悬停查看详情。鼠标移到事件左右边框时显示水平调整光标，直接拖拽边框可调整起止时间，无需先选中；拖拽事件内部可整体平移，开始和结束同步变化，时长保持不变。单击事件会保持选中；实际拖动后松开鼠标会取消选中。拖动时显示细刻度、蓝色起止时间和对齐线，靠近刻度或其他事件的边界会吸附；默认刻度间隔 15 分钟，2 倍以上为 5 分钟，4 倍为 1 分钟。按住 Alt 可关闭吸附，按分钟微调。移动范围限制在当天绘图区内。拖动时预览，松开后保存并更新明细，Esc 取消。跨天事件只允许调整当天可见的实际端点，整体平移仍保留完整时长。双击事件会直接在轨迹内编辑名称，Enter 或离开输入框保存，Esc 取消；右键已保存事件的「编辑详情」可修改备注等内容。按住 Ctrl 滚动鼠标滚轮，上滚放大、下滚缩小，范围为 1～4 倍，默认 1 倍显示全天；缩放以鼠标所在的时间点为中心。放大时自动增加分钟刻度，标签间隔随窗口宽度调整，避免文字重叠。普通滚轮横向移动，Shift+滚轮纵向移动。
6. 第一次单击事件明细只选中该行，选中后再单击名称、标签、开始或结束时间才进入对应单元格编辑。编辑中单击同一行的另一可编辑单元格，会保存当前修改并直接切换；单击另一行则先保存并选中该行，再次单击才编辑。名称按 Enter 或离开输入框保存，Esc 取消；单击空白区域一次即可关闭选择器并退出编辑，保存有效修改。输入无效或保存失败时保留当前输入和选中状态，阻止切换。Tab / Shift+Tab 保存并编辑下一列 / 上一列。时间也可关闭选择器后输入 HH:MM 或 YYYY-MM-DD HH:MM。本日用时自动计算。右键点击轨迹上的事件或明细记录，选择「删除」直接删除，不弹出确认框；明细选中后也可按 Del 删除。按 Ctrl 或 Shift 单击可多选并一起删除所选记录；编辑输入框时 Del 只删除文字。在轨迹任意位置右键选择「在此新增事件」，以点击位置附近的刻度为开始，默认持续一小时；临近 24:00 时允许持续到次日。
7. 左侧标签树只用于管理标签，点击不会筛选右侧记录。时间轴和列表始终显示所选日期的全部事件。
8. 用日期输入框、前后箭头或「今天」浏览日期。快捷键：Ctrl+N 在表格新增事件，Ctrl+C 复制时间轴或明细中所选事件，Ctrl+V 粘贴到当前浏览日期（保留时刻、完整跨日时长、名称、标签和备注，生成独立记录；支持多选，粘贴可以撤销），Ctrl+←/→ 切换日期，Del 直接删除所选事件，Ctrl+Z 撤销最近一次修改（新增、删除、编辑、拖拽以及创建或放弃草稿均可回退），Ctrl+Y 或 Ctrl+Shift+Z 重做。输入框中的 Ctrl+C / Ctrl+V 仍用于复制粘贴文字；未命名草稿粘贴后仍是草稿。
9. 轨迹和明细自动插入事件之间的空档，默认名称为「未定义」。按全部已记录事件和草稿覆盖的时间计算，重叠或相接不产生空档。空档可以跨午夜或跨多天：例如视频在 10 月 9 日 23:50 结束、睡觉在 10 月 10 日 00:06 开始，会生成一条完整的 23:50–次日 00:06 空档；两天界面分别显示对应部分，「本日用时」分别是 10 分钟和 6 分钟。两条记录之间完全没有普通事件的日期也显示空档。只生成两个普通事件之间的空闲时间；首条记录之前、最后一条记录之后都不补空档。旧版生成的首条记录之前的「未定义」行会在启动同步时自动清除。拖拽、调整时间、新增或删除事件时，空档同步更新；空档本身不能拖拽，起止时间也不能直接编辑（它的边缘就是相邻事件的端点，拖动边缘实际调整的是相邻事件）。空档会以带 undefined: 前缀的未分类行镜像到数据文件中（包括修改后的名称，例如「煮饭」「刷手机」），重启或导出后不丢失；边界变化时镜像行随派生结果调整并保留名称，空档消失时对应行自动删除。未定义状态以标签为准，未指定标签时使用灰色虚线显示，改名不会转成普通事件。在明细标签列或右键「设置标签」指定任意层级标签后，才将完整空档另存为普通事件。旧版只生成次日开头部分的跨天空档会在启动时补全并保留名称、备注。

10. 事件明细默认使用「时间顺序」视图，逐条显示原始记录。点击「汇总」后，按标签 ID 将记录归为一组，显示标签名、条数及当天累计用时；同一标签下的不同事件名称一起累计，展开后逐条保留原名称。不同标签分别显示。同组重叠时段只计一次，跨日事件仅计当天部分，缺少结束时间的记录标注待补全。按累计用时从多到少排列，未分类记录及未定义空档合为末尾的「未分类 / 未定义」区域，展开后保留每段的原名称。草稿逐条显示在前面。点击汇总行展开或收起，展开后每条仍能独立选择、编辑、右键管理和复制粘贴；Ctrl / Shift 多选遵循当前显示顺序。时间轴选择、新增和粘贴会自动展开并显示对应条目。「时间顺序 / 汇总」切换与「新增事件」位于同一行，列表直接从记录开始，不设额外标题行或列标题。两种视图显示相同记录。

事件占满时间轴绘图区的高度，并按每一段的并行数量均分。例如做饭 13:00–15:00、听播客 13:00–14:00，13:00–14:00 各占一半，14:00–15:00 做饭占满高度。明细条目与对应时间轴事件使用相同背景色。

时间轴和明细同步显示选中状态：底色加深，明细文字加粗，时间轴显示边框。点击时间轴或明细的空白处、标题等其他区域可取消选中。滚动条采用无纹路的细滑块，标签树、轨迹和明细只在内容溢出时显示滚动条。

列表中的「本日用时」只显示事件在选中日期内的时长。界面采用 Material 3 浅色主题，标签使用 Material 内置浅色色板区分。

删除标签前，必须先移走它的子标签和关联事件；这能避免历史记录失去分类。

## 记账

左侧窄图标栏切换「时间记录」和「记账」，悬停显示名称。记账左侧为独立的彩色标签树，点击标签聚焦金额框，按住 250 毫秒后拖动：行上方／下方的插入线调整同级顺序，中间高亮区域改变父级，标题空白处移至一级。主标签和子标签均支持排序，层级与顺序一次保存并可撤销；没有固定状态或三点菜单。展开／折叠及右键新增／修改／删除保持可用，管理窗口支持点击或右键编辑。移动和改名保留标签 ID 与历史账单关联，收支标签与时间标签独立。

两个工作区共用可切换的 Material 3 配色、白色圆角面板和统一控件样式，标题栏与侧栏背景连贯。顶部提供松石、靛蓝、暖沙、玫瑰、石板五种预设，默认石板，窄窗口从当前配色菜单选择。切换后记住选择，并保留未保存输入与模块状态。时间标签恢复彩色圆点和层级缩进，时间轴和事件明细保留现有组件；记账分类保留柔和底色与图标。布局参考 [Material 3 的界面层级规范](https://m3.material.io/styles/color/the-color-system)、[Actual Budget 的桌面报表](https://actualbudget.org/docs/reports/) 和 [Linear 的界面层级整理](https://linear.app/now/how-we-redesigned-the-linear-ui)。

新账本直接从零开始，无需填写初始化资金。已有账本保留原余额与全部历史账单；历史收支不会再次扣款。日常收支关联现金，现金可包含纸币、银行卡、微信与支付宝余额的合计；需要设置实际资金时使用「余额校准」。

默认支出标签为餐饮（早餐、午餐、晚餐、其他）、住房、日用、交通、服饰、爱好、医疗、充值、消费、购物、娱乐、缴费、其他。标签使用 Material 色板，子标签默认继承父标签色系并按树中顺序区分色阶，相同色系的一级标签也使用不同色阶；徽标使用清晰的底色和对比图标，也可自行选色；旧账本补充缺失的默认分类，保留已有名称、ID 和自定义分类。同名已有标签优先，成功保存后不会重新创建已删除的默认标签。

- 在任意层级标签旁填金额，**Enter / 数字键盘 Enter / Ctrl+Enter** 或「保存已填项目」一次保存所有已填支出与收入，包括折叠标签及切换收支类型后暂藏的输入；整批只写入一次、也可一次撤销。同日同类每次保存都是独立账单。金额框中 **↑ / ↓** 切换上一／下一金额框并自动滚动，**← / →** 移动文字光标，**Tab / Shift+Tab** 遵循输入框顺序。备注中 Enter 同样批量保存，Shift+Enter 换行；中文输入法组词时 Enter 交给输入法，确认文字后再保存。点击备注图标为各笔账单填写备注；收入从左侧「收入标签」录入。
- 日期默认今天，可输入、选择，或用左右箭头切换上一天／下一天。流水按天显示完整收支合计，未滚动加载的账单也计入，转账和校准除外。日期变化时清除未保存金额和备注；切换时间记录／记账会保留记账草稿，退出后丢弃。
- 点击收支流水可修改金额、日期、标签、备注或收支类型；右键或聚焦后按 **Shift+F10／菜单键** 打开账单操作，不显示三点按钮。所有流水均可单独修改备注，转账和余额校准也支持。修改备注不影响金额和余额。删除收支恢复对应余额；**Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z** 撤销或重做本次运行中已保存的账单，同时恢复流水和余额；金额、备注或日期输入框获得焦点时同样生效，未保存文字保持原样。
- 余额卡片右侧的「账户操作」菜单集中提供转账、余额校准和账户管理。「转账」选择转出、转入账户；「余额校准」填实际余额，预览并保存差额。转账不改变资金总额，校准会改变总额，两者不计入收入或支出统计。
- 「管理账户」提供新增、重命名、校准。默认现金账户和有关联记录的账户不能删除；非零账户须先转出余额。
- 右侧月份框、前后箭头和「本月」选择浏览月份。流水按日期降序排列，向下滚动加载更早月份；汇总始终属于所选月份。
- 「分类统计」支持按月／按年与支出／收入切换。环形图、标签明细显示金额、占比和笔数；宽窗口左右并列，小窗口上下排列。点击标签逐层查看，父标签自己的账单单列为「直接记录」，与子类汇总共同构成父类总额，每笔只计算一次。年份可输入或用前后箭头切换。

金额无效或保存失败时，保留原账单、余额、撤销历史和输入，显示可关闭的浮动提示或弹窗错误，可直接重试。验证与截图均使用隔离的合成数据。

第一版不包含银行同步、支付渠道明细、证券行情、预算或云同步。

## 数据文件

首次运行自动建立项目目录下的 `data/`：

| 文件 | 内容 |
| --- | --- |
| `tags.json` | 标签 ID、名称、父标签 ID，带版本号 |
| `events.csv` | 事件名称、标签 ID、开始/结束时间、备注 |
| `ledger.json` | 记账标签、颜色、拖动顺序、资金账户、余额及带备注的流水，独立版本 2 |
| `appearance.json` | 当前配色 ID，独立版本 1；首次切换主题后创建，不写入记录文件 |
| `.daymark.lock` | 防止两个窗口同时写入同一个数据目录的锁 |

标签示例：

```json
{
  "version": 1,
  "tags": [
    {"id": "work", "name": "主业", "parent_id": null},
    {"id": "embedded", "name": "嵌入式", "parent_id": "work"},
    {"id": "linux", "name": "Linux", "parent_id": "embedded"}
  ]
}
```

CSV 列固定为 `id,title,tag_id,start,end,notes`。时间格式为 `2026-10-07T09:00:00`，新记录精确到分钟；空 `tag_id` 表示未分类。CSV 使用 UTF-8 BOM，便于 Excel 显示中文。标签 ID 稳定，改名和移动只修改标签文件。

记账数据首次成功保存时才创建。`ledger.json` 中所有金额均为整数分，日期为无时区的 `YYYY-MM-DD`。`default_cash_account_id` 明确指定默认现金账户，流水保存 `account_id` 和 `affects_balance`，转账另存 `to_account_id`，校准金额为有符号差额；不依据账户名称或流水日期猜测余额关联。账户开账余额加上所有关联流水影响必须等于当前余额，读取时校验不一致会停止启动并保留原文件。记账账户与流水一次原子替换，不改动版本 1 的时间标签 JSON 和六列事件 CSV。

兼容记账版本 1 的 `accounts/categories/records/pinned` 结构（账户 `balance_cents`、流水 `amount_cents`）：保留余额、分类 ID 和全部收支，历史流水标记为不影响余额。无需初始化，首次成功保存升级为版本 2，不回放旧收支。不存在记账文件的原版时间记录目录可以直接使用。该兼容结构以合成样本测试验证。

旧版数据可以直接读取，启动时同步派生空档。已有秒数在只修改名称或分类时会保留。旧记录缺少结束时间时，列表显示「待补全」；补齐时间后才会显示在时间轴上。

保存采用同目录临时文件加原子替换。读取失败会显示错误并保留原文件，不会重建覆盖。不要在软件运行时手动修改数据；Excel 打开 CSV 时可能阻止保存，请先关闭文件。备份时关闭软件，复制整个 `data` 文件夹即可。

可以指定另一个数据目录，方便分开工作日志或测试：

```powershell
./start.ps1 --data-dir ./another-journal
```

## 项目结构与验证

```text
lib/
  main.dart           启动、数据目录和应用生命周期
  domain/             日历模型、并行分段、拖拽计算、整数金额和快照历史
  data/               JSON/CSV 校验、原子保存和进程锁
  application/        独立时间记录/记账串行事务控制器
  ui/                 标签树、时间轴、录入、账户管理和层级统计
windows/              Flutter 官方 Windows 桌面宿主
test/                 模型、存储、控制器和无窗口 Widget 交互回归
test/fixtures/        原版导出的合成兼容样本
tools/smoke_windows.ps1  私有非活动桌面的原生 Release 启动验证
```

运行格式化、静态检查和全部自动测试（Widget 测试不打开原生窗口）：

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
git diff --check
```

验证 Windows Release 的图标字体、真实启动、CSV BOM / 空档同步、第二实例拒绝和退出释放锁（合成数据、不可激活的私有桌面）：

```powershell
./tools/build_windows.ps1
./tools/smoke_windows.ps1
```

推荐使用 `./tools/build_windows.ps1` 构建发布版：脚本仅失效项目内的 Windows 发布资源缓存标记，再调用 Flutter 构建，避免增量构建沿用旧的图标字体子集。启动检查覆盖「时间顺序」「汇总」、所有内置记账分类徽标及备注图标，并为冷启动预留 30 秒。

界面截图也可以使用发布包的实际字体验证：

原生检查需要 Windows 桌面会话，私有桌面创建失败时直接停止；不会切换桌面或回退到当前桌面。所有测试工件位于 `.test-artifacts/`，不读取个人数据。CI 在 Windows 上执行格式化、静态检查、测试和 Release 构建。

测试覆盖标签关联保持、中文和换行 CSV、跨天与分段重叠显示、旧数据兼容、原子保存失败、损坏数据保护、右键和 Del 删除、拖拽操作、树状/日期/时间选择、窗口布局和单实例锁。交互回归测试通过鼠标按下/释放、键盘和滚轮事件验证单元格编辑、备注、同步选中与取消、弹窗关闭后的焦点恢复、时间轴缩放、端点调整和保持时长的整段移动，以及取消和失败保存后的数据保持。

这是一个单机最小版。时间采用本机本地时间，不做跨时区转换；暂未实现多标签事件、自动识别电脑活动、周/月报表、云同步和安装包。
