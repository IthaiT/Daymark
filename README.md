# Daymark

一个本地运行的 Flutter / Dart 桌面时间记录与记账工具。

Windows 界面采用共享的 Material 3 主题、面板和标签组件，内置 Noto Sans SC 中英文字体与 Material 色板。时间记录和记账的背景、字号、间距、圆角与控件一致。标签写入 JSON，事件写入 CSV，兼容原版数据；不需要 Web 服务。

## 开发环境

安装 Flutter stable（已验证 3.47.7 / Dart 3.13.5）及 Visual Studio 2022 的「使用 C++ 的桌面开发」工作负载。用 `flutter doctor -v` 检查 Windows 工具链。Flutter 插件链接需要 Windows 开发者模式或具备创建符号链接权限的终端。

```powershell
flutter pub get
flutter run -d windows
# 构建后双击 start.cmd，或运行 ./start.ps1
./tools/build_windows.ps1
```

发行时复制整个 `build/windows/x64/runner/Release/` 目录，包含 DLL 和 Flutter 的 `data/` 资源；单独复制 EXE 不足以运行。独立发行版默认将用户记录保存在 EXE 旁的 `journal/`，也可传入 `--data-dir`。仓库启动脚本始终默认使用项目原有的 `data/`。

## 功能

- 任意层级的标签：新增、重命名、移动到其他父标签。
- 手动记录事件的开始和结束时间，提供日历和小时、分钟选择器。
- 修改事件内容、标签和时间，删除事件。
- 按日期浏览横向时间轴和事件明细。
- 标签树右键管理、拖拽移动，事件使用树状下拉选择标签。
- 本地存储，不上传数据。
- 左侧图标栏切换「时间记录 / 记账 / 标签导图」，前两套分类独立，时间记录页保持原有录入流程。
- 标签导图：随应用打包的离线思维导图，拖动调整标签层级、折叠缩放、撤销恢复，改动自动校验并原子写入。
- 常用支出连续键盘录入、账户余额自动联动、转账、校准、月流水和逐层分类统计。

## 使用方法

1. 在左侧标签上右键，选择「新增子标签」「修改标签」或「删除标签」。在树的空白处右键可新增一级标签；双击只展开或收起分支。
2. 将标签拖到另一个标签上，整个分支会移动到该标签下。拖到树的空白处，或右键选择「移至一级标签」，可将分支移到顶层。不允许移动到自己或自己的子标签中。
3. 点击列表上方的「新增事件」、按 Ctrl+N，或双击表格空白处，直接生成一行草稿并聚焦第一列名称，无需填写新增弹窗。按 Tab 依次编辑开始时间、结束时间和标签；标签可输入搜索，也可保留「未分类」。每次新增都会生成独立草稿，表格会自动滚动到新草稿。默认接在所选日期最后一个完整事件或草稿的结束时间之后，持续一小时。当天没有完整事件时，今天从当前时间开始，其他日期从 09:00 开始；临近午夜可以跨日。若已有事件覆盖到次日，新草稿从当天 23:00 开始。新建事件的结束时间在本次浏览日期内、手动填写结束时间或拖拽调整之前，会随开始时间同步移动，保持建议时长；填写名称或标签后仍可继续调整。手动确认结束时间后，开始时间必须早于结束时间。未命名草稿只保留在内存中，切换日期或关闭软件会丢弃；Esc 先关闭选择器，再按一次取消当前编辑并放弃当前草稿。
4. 在明细中选中事件后，单击标签单元格打开可输入的树状下拉框。输入名称或标签路径即可过滤补全项，不区分大小写；搜索结果显示完整层级以区分重名标签。↑ / ↓ 选择补全项，Enter（含数字键盘 Enter）确认补全并关闭候选列表，光标留在标签框末尾继续编辑；Tab 确认并切换下一列；没有匹配项时保留输入供修改。也可展开分支并单击目标标签。标签弹窗沿用左侧标签栏的色点、层级缩进和选中样式。任意层级标签和「未分类」均可选择。名称为空时选择标签，会自动使用标签名并保存；已有名称保持原样。「未定义」空档选定标签后也默认使用标签名，已改名的空档保留名称。单击日期输入框选择日期，单击时间输入框选择小时和分钟，然后点击「确定」。按 Esc 可关闭选择器并继续输入；时间支持 HH:MM、HHmm（例如 2021 表示 20:21）以及带 YYYY-MM-DD 的完整日期时间。支持跨午夜，不需要输入秒。
5. 在时间轴上悬停查看详情。鼠标移到事件左右边框时显示水平调整光标，直接拖拽边框可调整起止时间，无需先选中；拖拽事件内部可整体平移，开始和结束同步变化，时长保持不变。单击事件会保持选中；实际拖动后松开鼠标会取消选中。拖动默认精确到分钟，不受标尺 15 分钟刻度限制，显示蓝色起止时间和对齐线；非常接近其他事件边界时会轻微吸附，吸附范围最多一分钟。按住 Alt 可关闭边界吸附。标尺细刻度仍按缩放显示 15 / 5 / 1 分钟，Ctrl+滚轮放大可更精确地定位。移动范围限制在当天绘图区内。拖动时预览，松开后保存并更新明细，Esc 取消。跨天事件只允许调整当天可见的实际端点，整体平移仍保留完整时长。双击事件会直接在轨迹内编辑名称，Enter 或离开输入框保存，Esc 取消；右键已保存事件的「编辑详情」可修改备注等内容。按住 Ctrl 滚动鼠标滚轮，上滚放大、下滚缩小，范围为 1～4 倍，默认 1 倍显示全天；缩放以鼠标所在的时间点为中心。放大时自动增加分钟刻度，标签间隔随窗口宽度调整，避免文字重叠。普通滚轮横向移动，Shift+滚轮纵向移动。
6. 第一次单击事件明细只选中该行，选中后再单击名称、标签、开始或结束时间才进入对应单元格编辑。编辑中单击同一行的另一可编辑单元格，会保存当前修改并直接切换；单击另一行则先保存并选中该行，再次单击才编辑。名称按 Enter 或离开输入框保存，Esc 取消；单击空白区域一次即可关闭选择器并退出编辑，保存有效修改。输入无效或保存失败时保留当前输入和选中状态，阻止切换。选中单条记录后，Tab / Enter 从名称开始编辑，Shift+Tab 从标签开始编辑。编辑时 Tab / Shift+Tab 保存并在当前记录的可编辑列内向后 / 向前循环（未定义空档跳过派生时间列），不会跳到工具栏；Esc 先关闭选择器，再次按下退出编辑。时间也可关闭选择器后输入 HH:MM 或 YYYY-MM-DD HH:MM。本日用时自动计算。右键点击轨迹上的事件或明细记录，选择「删除」直接删除，不弹出确认框；明细选中后也可按 Del 删除。按 Ctrl 或 Shift 单击可多选并一起删除所选记录；编辑输入框时 Del 只删除文字。在轨迹任意位置右键选择「在此新增事件」，以点击位置附近的刻度为开始，默认持续一小时；临近 24:00 时允许持续到次日。
7. 默认使用「时间轴」，可在原时间轴区域切换为「活动热力图」。时间轴模式下，左侧标签树用于管理标签，事件列表显示所选日期的全部事件；热力图模式下，点击标签切换它的年度图表，父标签右侧箭头仍用于展开和折叠，事件列表跟随热力图的标签范围。
8. 用日期输入框、前后箭头或「今天」浏览日期。快捷键：Ctrl+N 在表格新增事件，Ctrl+C 复制时间轴或明细中所选事件，Ctrl+V 粘贴到当前浏览日期（保留时刻、完整跨日时长、名称、标签和备注，生成独立记录；支持多选，粘贴可以撤销），Ctrl+←/→ 切换日期，Del 直接删除所选事件，Ctrl+Z 撤销最近一次修改（新增、删除、编辑、拖拽以及创建或放弃草稿均可回退），Ctrl+Y 或 Ctrl+Shift+Z 重做。输入框中的 Ctrl+C / Ctrl+V 仍用于复制粘贴文字；未命名草稿粘贴后仍是草稿。
9. 轨迹和明细自动插入事件之间的空档，默认名称为「未定义」。按全部已记录事件和草稿覆盖的时间计算，重叠或相接不产生空档。空档可以跨午夜或跨多天：例如视频在 10 月 9 日 23:50 结束、睡觉在 10 月 10 日 00:06 开始，会生成一条完整的 23:50–次日 00:06 空档；两天界面分别显示对应部分，「本日用时」分别是 10 分钟和 6 分钟。两条记录之间完全没有普通事件的日期也显示空档。只生成两个普通事件之间的空闲时间；首条记录之前、最后一条记录之后都不补空档。旧版生成的首条记录之前的「未定义」行会在启动同步时自动清除。拖拽、调整时间、新增或删除事件时，空档同步更新；空档本身不能拖拽，起止时间也不能直接编辑（它的边缘就是相邻事件的端点，拖动边缘实际调整的是相邻事件）。空档会以带 undefined: 前缀的未分类行镜像到数据文件中（包括修改后的名称，例如「煮饭」「刷手机」），重启或导出后不丢失；边界变化时镜像行随派生结果调整并保留名称，空档消失时对应行自动删除。未定义状态以标签为准，未指定标签时使用灰色虚线显示，改名不会转成普通事件。在明细标签列或右键「设置标签」指定任意层级标签后，才将完整空档另存为普通事件。旧版只生成次日开头部分的跨天空档会在启动时补全并保留名称、备注。

10. 事件明细的列顺序为名称、开始时间、结束时间、标签、本日用时。默认「时间顺序」视图将所有事件与未定义空档统一按开始时间排序，未分类记录也按实际时间穿插显示，与时间轴保持一致，便于连续查看一天的时间。未编辑时，↑ / ↓ 按当前表格顺序选中上一条 / 下一条事件并自动滚动，Enter 编辑所选事件的名称。点击「汇总」后，按标签 ID 将记录归为一组，显示标签名、条数及当天累计用时；同一标签下的不同事件名称一起累计，展开后逐条保留原名称。不同标签分别显示。同组重叠时段只计一次，跨日事件仅计当天部分，缺少结束时间的记录标注待补全。按累计用时从多到少排列，未分类记录及未定义空档合为末尾的「未分类 / 未定义」区域。草稿逐条显示在前面。点击汇总行展开或收起，展开后每条仍能独立选择、编辑、右键管理和复制粘贴；Ctrl / Shift 多选遵循当前显示顺序。时间轴选择、新增和粘贴会自动展开并显示对应条目。「时间顺序 / 汇总」切换与「新增事件」位于同一行，列表直接从记录开始，不设额外标题行或列标题。两种视图显示相同记录。

活动热力图按当前浏览日期所在的自然年展示，每列一周、每格一天；图表内的年份箭头可切换年份。图表上方的搜索框按名称或完整路径搜索，不区分大小写；选中后清空输入并保留搜索框焦点，可以继续搜索、添加其他标签。搜索框初始即预留固定的两行标签区域；所选标签直接显示在框内，使用与事件表一致的颜色，数量较多时换行，超出区域后纵向滚动，搜索框、年份和热力图的位置保持固定。标签仅显示名称，悬停可查看完整路径；点击 × 移除，移除最后一个标签恢复全部范围。已选标签仍保留在下拉搜索树中，再次选择不会重复添加。「未分类」也可以与其他标签一起选择。↑ / ↓ 切换搜索结果，Enter（含数字键盘 Enter）确认，Esc 取消当前搜索并保留已选标签；中文输入法组词时不会提前确认。重名标签显示完整路径。点击左侧标签树会直接切换到该单个标签。

多个标签按并集合并，父标签包含自己的记录及全部子标签；同时选择父、子标签时不会重复计算事件。跨午夜事件分别计入各天；所选范围内的重叠时间只计一次，开启「并行时段平均分摊」后仍按全部同时发生的事件分摊。只统计已保存且有结束时间的普通事件，草稿、待补全记录和自动派生的未定义空档不参与热力统计。

每组所选标签和年份独立使用自己的单日峰值计算九档正时长色阶，零时长使用中性灰色；单标签配色跟随标签色系，多标签与全部标签使用 Material 绿色。峰值为 12 小时时，9、11、12 小时落入不同色阶；峰值从 10 小时增至 20 小时后，10 小时由最深色调整为中间色。累计时长、活跃天数和单日峰值位于图表下方左侧，少到多的色阶图例靠右；悬停方格查看日期、标签和具体时长。点击方格后，下方事件表只显示该日符合所选标签范围的普通事件，「时间顺序」和「汇总」遵循相同筛选。当天待补全记录仍可查看；新增、粘贴和编辑中的条目暂时保留，方便补全标签。修改事件、标签层级或重叠设置后立即重新统计；切回时间轴再返回时保留标签选择，重新进入应用仍默认时间轴。数据文件格式保持不变。

事件占满时间轴绘图区的高度，并按每一段的并行数量均分。例如做饭 13:00–15:00、听播客 13:00–14:00，13:00–14:00 各占一半，14:00–15:00 做饭占满高度。明细条目与对应时间轴事件使用相同背景色。

时间轴和明细同步显示选中状态：底色加深，明细文字加粗，时间轴显示边框。点击时间轴或明细的空白处、标题等其他区域可取消选中。滚动条采用无纹路的细滑块，标签树、轨迹和明细只在内容溢出时显示滚动条。

列表中的「本日用时」只显示事件在选中日期内的时长。界面采用 Material 3 浅色主题，标签使用 Material 内置浅色色板区分。

删除标签前，必须先移走它的子标签和关联事件；这能避免历史记录失去分类。

## 标签导图

左侧图标栏第三项「标签导图」使用随应用打包的 [SimpleMindMap](https://github.com/wanglin2/mind-map)（MIT）在 WebView2 中显示当前标签树，不访问网络。系统需要 Microsoft Edge WebView2 运行时，Windows 10/11 通常已自带。

- 默认打开「Daymark」全部标签视图，画布占满内容区。「Daymark」是虚拟根节点，不写入文件；右键任意标签选择「进入」进入它的子树，在当前子树根上右键可「返回 Daymark」。
- 父节点在左，子节点向右。拖动节点到另一个节点上改变父级；拖到空白处移到当前根下。同级顺序在保存时按 Daymark 现有规则统一排序。
- Tab 新增子标签并立即输入，Enter 新建同级标签；双击节点或按 F2 在节点内改名，不弹出对话框。Delete 直接删除叶子标签，不显示确认框；当前根标签不能删除，仍有子标签或事件关联的标签会说明原因。
- 改动会自动保存：每次拖动、改名或增删后约半秒，合并其他页面新增的标签，再由 Daymark 控制层校验同级重名、循环和事件关联，整表原子写入现有标签格式。子树之外的标签保持不变；保存失败时保留草稿和输入并显示提示。Ctrl+S 可立即提交正在编辑的名称。
- 配色跟随顶部五种主题实时更新。节点右侧圆点折叠或展开分支；底部工具栏提供新增、重命名、删除、缩小、适应画布和放大。滚轮平移，Ctrl+滚轮缩放，Ctrl+0 适应画布；缩放、折叠和滚动位置属于临时视图状态，不写入文件。
- Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z）撤销或恢复，F2 就地改名，Delete 删除。标签 ID 保持不变，拖动和改名不会影响事件关联；删除仍有事件的标签会被拒绝。

## 记账

左侧窄图标栏切换「时间记录」和「记账」，悬停显示名称。记账左侧为独立的彩色标签树，点击标签聚焦金额框，按住 250 毫秒后拖动：行上方／下方的插入线调整同级顺序，中间高亮区域改变父级，标题空白处移至一级。主标签和子标签均支持排序，层级与顺序一次保存并可撤销；没有固定状态或三点菜单。展开／折叠及右键新增／修改／删除保持可用，管理窗口支持点击或右键编辑。移动和改名保留标签 ID 与历史账单关联，收支标签与时间标签独立。

两个工作区共用可切换的 Material 3 配色、白色圆角面板和统一控件样式，标题栏与侧栏背景连贯。顶部提供松石、靛蓝、暖沙、玫瑰、石板五种预设，默认石板，窄窗口从当前配色菜单选择。切换后记住选择，并保留未保存输入与模块状态。时间标签恢复彩色圆点和层级缩进，时间轴和事件明细保留现有组件；记账分类保留柔和底色与图标。布局参考 [Material 3 的界面层级规范](https://m3.material.io/styles/color/the-color-system)、[Actual Budget 的桌面报表](https://actualbudget.org/docs/reports/) 和 [Linear 的界面层级整理](https://linear.app/now/how-we-redesigned-the-linear-ui)。

新账本直接从零开始，无需填写初始化资金。已有账本保留原余额与全部历史账单；历史收支不会再次扣款。日常收支关联现金，现金可包含纸币、银行卡、微信与支付宝余额的合计；需要设置实际资金时使用「余额校准」。

默认支出标签为餐饮（早餐、午餐、晚餐、其他）、住房、日用、交通、服饰、爱好、医疗、充值、消费、购物、娱乐、缴费、其他。标签使用 Material 色板，子标签默认继承父标签色系并按树中顺序区分色阶，相同色系的一级标签也使用不同色阶；徽标使用清晰的底色和对比图标，也可自行选色；旧账本补充缺失的默认分类，保留已有名称、ID 和自定义分类。同名已有标签优先，成功保存后不会重新创建已删除的默认标签。

- 在任意层级标签旁填金额，**Enter / 数字键盘 Enter / Ctrl+Enter** 或「保存已填项目」一次保存所有已填支出与收入，包括折叠标签及切换收支类型后暂藏的输入；整批只写入一次、也可一次撤销。同日同类每次保存都是独立账单。金额框中 **↑ / ↓** 切换上一／下一金额框并自动滚动，**← / →** 移动文字光标，**Tab / Shift+Tab** 遵循输入框顺序。备注中 Enter 同样批量保存，Shift+Enter 换行；中文输入法组词时 Enter 交给输入法，确认文字后再保存。点击备注图标为各笔账单填写备注；收入从左侧「收入标签」录入；在标签的新增／修改分类窗口选择入账账户，默认现金。绑定会保存到本地账本，重启后仍保留，工资、公积金等可分别自动入账；更换绑定只影响之后录入的流水，已有流水的账户可在账单编辑窗口单独修改。
- 日期默认今天，可输入、选择，或用左右箭头切换上一天／下一天。流水按天显示完整收支合计，未滚动加载的账单也计入，转账和校准除外。日期变化时清除未保存金额和备注；切换时间记录／记账会保留记账草稿，退出后丢弃。
- 点击收支流水可修改金额、日期、标签、账户、备注或收支类型；点击转账可修改金额、转出和转入账户、日期及备注，点击余额校准可修改账户、当前实际余额、日期及备注。修改时先撤销原校准对账户的影响，再按输入的实际余额重新计算校准金额，所选账户最终余额等于输入值；右键或聚焦后按 **Shift+F10／菜单键** 打开账单操作，不显示三点按钮。所有流水均可单独修改备注，转账和余额校准也支持。修改备注不影响金额和余额。删除收支恢复对应余额；**Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z** 撤销或重做本次运行中已保存的账单，同时恢复流水和余额；金额、备注或日期输入框获得焦点时同样生效，未保存文字保持原样。
- 余额卡片右侧的「账户操作」菜单集中提供转账、余额校准和账户管理。「转账」选择转出、转入账户；「余额校准」填实际余额并保存。转账不改变资金总额，校准会改变总额，两者不计入收入或支出统计。
- 「管理账户」提供新增、重命名、校准。默认现金账户和有关联记录的账户不能删除；非零账户须先转出余额。
- 右侧月份框、前后箭头和「本月」选择浏览月份。流水按日期降序排列，向下滚动加载更早月份；汇总始终属于所选月份。
- 「分类统计」支持按月／按年与支出／收入切换。环形图、标签明细显示金额、占比和笔数；宽窗口左右并列，小窗口上下排列。点击标签逐层查看，父标签自己的账单单列为「直接记录」，与子类汇总共同构成父类总额，每笔只计算一次。年份可输入或用前后箭头切换。「筛选标签」支持排除所选或仅包含所选，选择父标签会包含所有子标签，也可筛选未分类；图表与明细按筛选后的总额重算占比，可随时重置。鼠标悬停环形图色块时，中心显示对应标签、金额及占比，并高亮该色块。筛选在当前统计视图内保留，切换收支类型或离开统计后重置。

金额无效或保存失败时，保留原账单、余额、撤销历史和输入，显示可关闭的浮动提示或弹窗错误，可直接重试。验证与截图均使用隔离的合成数据。

收入标签的默认账户保存在可选字段 `income_accounts`（标签 ID 到账户 ID 的映射），未绑定时使用默认现金账户；旧版账本缺少该字段时兼容读取。绑定中的账户须先解除标签绑定后才能删除。

第一版不包含银行同步、支付渠道明细、证券行情、预算或云同步。

## 数据文件

首次运行自动建立项目目录下的 `data/`：

| 文件 | 内容 |
| --- | --- |
| `tags.json` | 标签 ID、名称、父标签 ID，带版本号 |
| `events.csv` | 事件名称、标签 ID、开始/结束时间、备注 |
| `ledger.json` | 记账标签、颜色、拖动顺序、收入标签入账账户、资金账户、余额及带备注的流水，独立版本 2 |
| `appearance.json` | 当前配色 ID，独立版本 1；首次切换主题后创建，不写入记录文件 |
| `settings.json` | 是否自动生成未定义事件与拖动颗粒度，独立版本 1；首次保存设置后创建 |
| `.daymark.lock` | 防止两个窗口同时写入同一个数据目录的锁 |

标签示例：

```json
{
  "version": 1,
  "tags": [
    {"id": "work", "name": "主业", "parent_id": null},
    {"id": "embedded", "name": "嵌入式", "parent_id": "work"},
    {"id": "linux", "name": "Linux", "parent_id": "embedded"}
  ]
}
```

CSV 列固定为 `id,title,tag_id,start,end,notes`。时间格式为 `2026-10-07T09:00:00`，新记录精确到分钟；空 `tag_id` 表示未分类。CSV 使用 UTF-8 BOM，便于 Excel 显示中文。标签 ID 稳定，改名和移动只修改标签文件。

记账数据首次成功保存时才创建。`ledger.json` 中所有金额均为整数分，日期为无时区的 `YYYY-MM-DD`。`default_cash_account_id` 明确指定默认现金账户，流水保存 `account_id` 和 `affects_balance`，转账另存 `to_account_id`，校准金额为有符号差额；不依据账户名称或流水日期猜测余额关联。账户开账余额加上所有关联流水影响必须等于当前余额，读取时校验不一致会停止启动并保留原文件。记账账户与流水一次原子替换，不改动版本 1 的时间标签 JSON 和六列事件 CSV。

兼容记账版本 1 的 `accounts/categories/records/pinned` 结构（账户 `balance_cents`、流水 `amount_cents`）：保留余额、分类 ID 和全部收支，历史流水标记为不影响余额。无需初始化，首次成功保存升级为版本 2，不回放旧收支。不存在记账文件的原版时间记录目录可以直接使用。该兼容结构以合成样本测试验证。

旧版数据可以直接读取，启动时同步派生空档。已有秒数在只修改名称或分类时会保留。旧记录缺少结束时间时，列表显示「待补全」；补齐时间后才会显示在时间轴上。

左下角的设置按钮可以关闭相邻事件之间「未定义」记录的自动生成。关闭后这些记录只是从界面隐藏，已填写的名称与备注仍保留在 CSV 中，重新开启会按当前事件重新派生并恢复对应名称；也可以把拖动与调整起止时间的颗粒度设为 1、5、10、15、30 或 60 分钟。设置保存在独立的 `settings.json`，不改动事件 CSV 和标签 JSON。设置无法读取时使用默认值，原文件保持不变。

保存采用同目录临时文件加原子替换。读取失败会显示错误并保留原文件，不会重建覆盖。不要在软件运行时手动修改数据；Excel 打开 CSV 时可能阻止保存，请先关闭文件。备份时关闭软件，复制整个 `data` 文件夹即可。

可以指定另一个数据目录，方便分开工作日志或测试：

```powershell
./start.ps1 --data-dir ./another-journal
```

## 项目结构与验证

```text
lib/
  main.dart           启动、数据目录和应用生命周期
  domain/             日历模型、并行分段、拖拽计算、整数金额和快照历史
  data/               JSON/CSV 校验、原子保存和进程锁
  application/        独立时间记录/记账串行事务控制器
  ui/                 标签树、时间轴、录入、账户管理和层级统计
windows/              Flutter 官方 Windows 桌面宿主
assets/mindmap/       SimpleMindMap 离线页面、样式、脚本和第三方许可证
test/                 模型、存储、控制器和无窗口 Widget 交互回归
test/fixtures/        原版导出的合成兼容样本
tools/smoke_windows.ps1  私有非活动桌面的原生 Release 启动验证
```

运行格式化、静态检查和全部自动测试（Widget 测试不打开原生窗口）：

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
git diff --check
```

验证 Windows Release 的图标字体、真实启动、CSV BOM / 空档同步、第二实例拒绝和退出释放锁（合成数据、不可激活的私有桌面）：

```powershell
./tools/build_windows.ps1
./tools/smoke_windows.ps1
```

推荐使用 `./tools/build_windows.ps1` 构建发布版：脚本仅失效项目内的 Windows 发布资源缓存标记，再调用 Flutter 构建，避免增量构建沿用旧的图标字体子集。启动检查覆盖「时间顺序」「汇总」、所有内置记账分类徽标及备注图标，并为冷启动预留 30 秒。

界面截图也可以使用发布包的实际字体验证：

原生检查需要 Windows 桌面会话，私有桌面创建失败时直接停止；不会切换桌面或回退到当前桌面。所有测试工件位于 `.test-artifacts/`，不读取个人数据。CI 在 Windows 上执行格式化、静态检查、测试和 Release 构建。

测试覆盖标签关联保持、中文和换行 CSV、跨天与分段重叠显示、旧数据兼容、原子保存失败、损坏数据保护、右键和 Del 删除、拖拽操作、树状/日期/时间选择、窗口布局和单实例锁。标签导图另有独立回归测试（`test/tag_map_test.dart`），覆盖树映射、稳定 ID、新节点分配、移动/删除规则、同级重名和整表原子保存；导图前端用无头浏览器和合成标签树验证新增、重命名、拖动、撤销/恢复和删除，不启动可见窗口。交互回归测试通过鼠标按下/释放、键盘和滚轮事件验证单元格编辑、备注、同步选中与取消、弹窗关闭后的焦点恢复、时间轴缩放、端点调整和保持时长的整段移动，以及取消和失败保存后的数据保持。

这是一个单机最小版。时间采用本机本地时间，不做跨时区转换；暂未实现多标签事件、自动识别电脑活动、周/月报表、云同步和安装包。
